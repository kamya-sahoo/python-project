# StudyMate — Smart Study Companion

A responsive, front-end study planner prototype built with HTML, CSS and JavaScript.

## Features
- Personal dashboard with today's schedule, tasks, study time and exam countdown
- Add subjects and topics; tick off completed topics
- Add assignments, due dates and completion status
- Weekly timetable with study sessions
- Pomodoro focus timer with short and long breaks
- Study progress charts and weekly performance summary
- Browser reminders for tasks due today or tomorrow
- LocalStorage persistence — your data stays in this browser

## Run the project
1. Extract `StudyMate.zip`.
2. Open the `studymate` folder.
3. Double-click `index.html` or open it in a browser.

No installation or backend is required. An internet connection is needed to load Chart.js and Google Fonts from their CDNs. The planner itself works locally in the browser.

## Notes
- This is a prototype; it does not send push notifications or synchronise data across devices.
- Data is saved in the browser's LocalStorage. Clearing browser site data will remove it.
- To reset the demo data, clear Local Storage for the page and refresh.
